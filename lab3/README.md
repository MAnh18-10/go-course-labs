# Лабораторная работа 3

## Задания

1. Пакет `mathutils` с функцией `Factorial`.
2. Использование пакета для факториала числа.
3. Пакет `stringutils` с функцией `Reverse`.
4. Массив из 5 целых чисел.
5. Срез из массива: добавление и удаление.
6. Самая длинная строка в срезе строк.

## Структура

```
lab3/
├── go.mod
├── main.go
├── mathutils/
│   └── factorial.go
└── stringutils/
    └── reverse.go
```

## Запуск

```bash
go run main.go
```

## Что вводить

1. Число (например, `5`) — для факториала.
2. Строку (например, `привет`) — для переворота.

## Ожидаемый вывод

```
Введите число для факториала: 5
Факториал 5 = 120
Введите строку для переворота: привет
Перевёрнутая строка: тевирп
Массив: [10 20 30 40 50]
После добавления: [10 20 30 40 50 60 70]
После удаления индекса 2: [10 20 40 50 60 70]
Самая длинная строка: программирование
```
